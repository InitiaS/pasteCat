复制过的内容，下一秒就找不到了。pasteCat 把最近复制的内容留在手边：按一下快捷键唤出面板，选中内容，它自动粘贴回你原来输入的位置。

## 功能

- **自动粘贴回原应用**：选中后自动切回原来的窗口并粘贴，无需手动 ⌘V
- **按住 ⌘ 多选合并**：按住 ⌘ 用鼠标点选多条，松开 ⌘ 时文本类内容自动合并成一段一次粘贴
- **搜索**：按内容关键词即时过滤历史
- **三种视图**：卡片 / 紧凑 / 列表，适配不同使用习惯
- **排除规则**：把密码管理器等应用加入排除列表，其复制内容不会被采集
- **置顶**：常用内容固定在顶部，清理历史时也会优先保留
- **内容类型识别**：文本、链接、颜色、图片、文件，不同类型不同展示

## 下载与安装

1. 前往 [Releases](../../releases/latest) 下载最新版 `pasteCat-v1.0.0.dmg`
2. 双击打开 DMG，把 **pasteCat** 拖进「应用程序」文件夹
3. 首次打开时 macOS 可能会拦截（应用未经过 Apple 公证），按下面任一方式放行：
   - **方式 A**：在「应用程序」里按住 Control 点击 pasteCat → 选「打开」→ 再点「打开」
   - **方式 B**：打开「系统设置 → 隐私与安全性」，拉到最底部，点击关于 pasteCat 的「仍要打开」
   - **方式 C**（若提示「已损坏」）：终端执行
     ```bash
     xattr -dr com.apple.quarantine /Applications/pasteCat.app
     ```
4. 首次使用「自动粘贴」时，按引导授予**辅助功能**权限（系统设置 → 隐私与安全性 → 辅助功能）。不授权也能用，只是选中后需要手动 ⌘V。

## 系统要求

- macOS 13 (Ventura) 或更高版本
- Apple Silicon 与 Intel 均可（Universal 二进制）

## 使用

| 操作 | 说明 |
| --- | --- |
| `⇧⌘V` | 唤出 / 隐藏剪贴板面板（可在设置中修改） |
| `↑` `↓` | 移动选择 |
| `↵` | 粘贴选中项 |
| `Esc` | 关闭面板 |
| 按住 `⌘` + 鼠标点选 | 多选，松开 `⌘` 时合并粘贴 |
| 直接点击条目 | 立即粘贴该条 |
| 点击面板外 | 关闭面板（「置顶」开启时除外） |

## 隐私

pasteCat **不含任何网络代码**，不联网、无账号、无统计、无遥测。所有剪贴板数据只保存在你自己的电脑上：

```
~/Library/Application Support/pasteCat/
```

## 关于免费版

本版本为免费版，剪贴板历史上限固定为 **6 条**。如果你希望有更大的历史上限与更多进阶能力，可以关注后续版本。

## 常见问题

**Q：提示「无法验证开发者」或「Apple 无法检查其是否包含恶意软件」？**
应用未经过 Apple 公证（需要开发者账号的付费公证流程）。按安装步骤第 3 条放行即可，这不代表应用有风险，你可以从源码能力层面验证它的行为：它不发起任何网络请求。

**Q：为什么需要辅助功能权限？**
「自动粘贴回原应用」需要模拟一次 ⌘V 按键，macOS 规定这类操作必须由用户显式授权。所有剪贴板工具都绕不开这一步。不授权时应用会自动降级为「只复制，请手动 ⌘V」。

**Q：为什么历史只有 6 条？**
这是免费版的设定。上限会在每次复制时自动生效，超出部分按时间从旧到新清理，置顶内容优先保留。

**Q：如何卸载？**
把「应用程序」中的 pasteCat 拖到废纸篓即可。若要一并清除数据，删除 `~/Library/Application Support/pasteCat/` 目录。若开启了开机自启，请先在设置里关闭。
